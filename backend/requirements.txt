# Tested on Python 3.12 (recommended). Every pin below has a pre-built binary
# wheel for CPython 3.12 on Windows, macOS and Linux, so `pip install` never
# compiles pandas or numpy from source and Visual Studio Build Tools are NOT
# required.
#
# Python 3.13/3.14 are NOT recommended yet: several scientific wheels lag behind
# new CPython releases, and pip then falls back to building from source, which
# is exactly what produces the
#   "metadata-generation-failed" / Meson / vswhere.exe
# errors. Create the environment with Python 3.12:
#
#   py -3.12 -m venv venv          (Windows)
#   python3.12 -m venv venv        (macOS/Linux)
#
# No database driver is required anywhere: this project uses local files only.
